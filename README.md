# السبورة الذكية | SmartBoard

منصة سبورة تفاعلية للمعلمين في المدارس والجامعات.

## الميزات

- ✏️ قلم وممحاة بأحجام وألوان متعددة
- 📏 أشكال: خط، سهم، مستطيل، دائرة
- 🔤 إضافة نص عربي
- 📝 ملاحظات لاصقة ملونة
- 🔴 مؤشر ليزر للتأشير
- 🎨 ملصقات إيموجي ممتعة
- ∑ رموز رياضية سريعة
- 📄 صفحات متعددة
- ↩ تراجع / إعادة
- ⬇ حفظ كصورة PNG
- ⛶ وضع ملء الشاشة
- خلفيات: أبيض / شبكة / أسطر / داكن
- دعم اللمس والأجهزة اللوحية
- واجهة عربية بالكامل

## التشغيل

```bash
npm install
npm run dev
```
